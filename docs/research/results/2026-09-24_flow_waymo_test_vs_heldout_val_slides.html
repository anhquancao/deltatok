Caveats — what this comparison does not establish

Two sets, one checkpoint, one noise draw per pass

Not controlled
  • FD sample size. 256 vs 1000 vectors in 1536 dims. The floor ratio is a workaround, not a validated correction. A test pass with eval_num_items=128 would match n.
  • Tokenizer exposure. 30 of the 32 val scenes were in the tokenizer's training data; no test scene was.
  • Windowing. Val uses the 4 non-overlapping windows per scene; test draws 500 sliding windows over 202 scenes.
  • Scene count. 32 vs 202 scenes. Per-item losses are not saved, so there are no confidence intervals.
Scope
  • One checkpoint. The 5-frame arm BSC 46250781 at iter 100k. Whether val and test rank arms the same way is not tested.
  • ODE sampler, steps ≤ 20, cam 0. No decode visuals.
  • Token-space losses cannot rank this. MSEToken and LossFlow are slightly lower on test, the opposite of the geometry.
  • Next arm uses the test set. The all-dataset ctx2fwd8 run evaluates on this Waymo test set, KITTI and nuScenes, 256 windows each.
