what is measured — one shared eval set, today's eval code

Every run is read on the same KITTI 206 windows, at gap 1, with the same code. Stage 1's weights were copied over and evaluated once.

what the eval measures
  • Gap 1. LossRecon and the geometry losses decode each adjacent pair of a 5-frame window, 0.5 s apart. The flow also encodes gap-1 deltas.
  • vs origin = *_PredVsOrig: decoded from the reconstructed tokens, against the origin, DA3's decode of the true tokens. Tokenizer error only. vs GT = *_PredVsGT, on LiDAR pixels.
  • _AR: the same pairs, each decoded from the previous prediction, 4 steps.
  • _Comp: a random t0 < t1 < t2 (gaps 2–4), decoding za + zb from t0.
Why KITTI 206 only. It is the one set every BSC run logged. The flow tokenizer's nuScenes set is the corrupted pre-09-30 copy.

checks & caveats

Same windows and the same eval code in all four runs. The read is one draw per arm, with several knobs changed at once.

checks
  • Same windows. Origin vs GT on KITTI 206 is identical in all four runs at 4 GPUs: 1.6566 / 1.0837 / 2.4022.
  • Stage 1 loads whole. The copy md5-matches Jean Zay, and all 554 tensors match today's architecture in name and shape, so the strict=False load leaves nothing random.
  • Same eval code. _eval_one_loader is unchanged between the flow tokenizer's code (7704517) and HEAD. The one removed line is a whitened-recon metric that run never logged.
  • 8 GPUs moves masked metrics by ≤0.5%. From compose's ep 20, origin vs GT reads 1.6543 / 2.3951 on KITTI (−0.14% / −0.30%), and −0.08% / −0.48% on nuScenes. Raymap and LossRecon are unchanged.
  • Why it moves: each batch averages over its own LiDAR pixels and is then weighted by batch size, so the result depends on how windows group into batches.
caveats
  • One draw per arm. Seed 1 vs seed 2. Stuck-or-escape was a random draw on the old recipe (prior deck).
  • Several knobs at once. The new arms change seed, layer_scale_init and 2 hops → 3 pairs. Stage 1 also differs in SIGReg 0.05, pool 8192, pair-only training and data sampling.
  • KITTI 206 is one drive. The window-sampling floor is ~2.2%.
  • Reconstruction only. No flow has been trained on either new tokenizer, so nothing here says the forecast improves.
  • _Comp is a fresh random draw every eval and every GPU count.
