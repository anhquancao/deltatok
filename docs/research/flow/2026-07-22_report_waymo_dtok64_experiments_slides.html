The decoder is the wall

copy = output the input as-is: z_t = t·x + (1−t)·ε, so x̂ = z_t/t — near t=1 the input is almost clean, nearly perfect for free. Losing to it = the network re-synthesizes everything (no input skip) → ~1% ceiling.

v = (x̂−z)/clamp(1−t, .05) amplifies the 1% floor ×400 → ~0.12 junk: 0.160 + 0.125 ≈ 0.285.
